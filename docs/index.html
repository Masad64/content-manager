After downloading

  1. Windows: run the .exe. If Windows SmartScreen appears, click More info → Run anyway.
  2. Mac: open the .dmg and drag Munshi into Applications. First launch: right-click the app → Open.
  3. Open Munshi and follow the built-in “📺 How to use” tab for a quick tour.
